## معرفی پروژه

این پروژه یک **پوسته (Skin) جایگزین برای Kiwix** است که هدف آن بهبود ظاهر و تجربه کاربری رابط وب Kiwix می‌باشد.

## این پروژه دقیقاً چیست؟

به طور ساده، این پروژه یک **پوسته بهتر برای Kiwix** است.  
رابط پیش‌فرض Kiwix ظاهر نسبتاً قدیمی و محدودی دارد و شخصی‌سازی آن نیز به‌سادگی امکان‌پذیر نیست. این پروژه مجموعه‌ای از فایل‌های **HTML، CSS و JavaScript** را فراهم می‌کند که جایگزین رابط پیش‌فرض شده و ظاهر و تجربه کاربری بهتری ارائه می‌دهد.

## نحوه کار پروژه

این پوسته به جای تغییر مستقیم در سورس Kiwix، از طریق **وب‌سرور Nginx** اعمال می‌شود.

در این روش:

- فایل‌های `HTML`، `CSS` و `JS` به صورت دستی روی سرور قرار داده می‌شوند.
- Nginx این فایل‌ها را **به جای فایل‌های رابط پیش‌فرض Kiwix سرو می‌کند**.
- در نتیجه بدون دست زدن به باینری یا سورس Kiwix، رابط کاربری آن تغییر می‌کند.

به این ترتیب می‌توان ظاهر Kiwix را به راحتی تغییر داد یا توسعه داد، بدون اینکه نیاز به تغییر در خود نرم‌افزار باشد.

## چرا این روش استفاده شده است؟

پوسته پیش‌فرض Kiwix داخل **کتابخانه‌ها و باینری برنامه embed شده است**.  
به همین دلیل:

- امکان ویرایش مستقیم فایل‌های رابط کاربری وجود ندارد.
- برای هر تغییری باید **کل پروژه Kiwix مجدداً کامپایل شود**.

این کار هم زمان‌بر است و هم برای اکثر کاربران عملی نیست.

بنابراین در این پروژه با استفاده از **Nginx و سرو فایل‌های استاتیک جایگزین**، این محدودیت دور زده شده و امکان شخصی‌سازی رابط کاربری Kiwix به شکل ساده‌تری فراهم شده است.
